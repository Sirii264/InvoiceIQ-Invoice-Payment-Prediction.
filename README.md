
# InvoiceIQ
## Invoice Payment Delay & Cash-Flow Intelligence Platform

### Project Overview
An AI/ML project designed to analyse invoice payments,
predict payment delays, assess customer payment risk,
and forecast future cash collections.

### Week 1: Data Cleaning and Preprocessing

Dataset: Global B2B Invoice & Payments Dataset

Original Records: 2,000,000
Original Columns: 31
Final Columns: 35

### Technologies Used
- Python
- Pandas
- NumPy
- Jupyter Notebook

### Activities Completed
1. Dataset loading
2. Data understanding
3. Missing value analysis
4. Duplicate detection
5. Date conversion
6. Text standardisation
7. Feature engineering
8. Data validation
9. Data dictionary creation
10. Column mapping

### Features Created
- days_to_pay
- payment_delay
- paid_late
- invoice_status
